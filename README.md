# Compiler Design

Coursework and lab programs for Compiler Design at SIMATS Engineering. The assignments cover lexical analysis, parsing, syntax-directed translation, intermediate code generation, and optimisation.

| Assignment | Topic |
| --- | --- |
| [Assignment 1](assignments/ThreatRule-Assignment-Report/) | ThreatRule lexical analysis with Flex |
| [Assignment 2](assignments/Assignment-2/) | Syntax analysis, parser construction, error recovery, and Flex/Bison |
| [Assignment 3](assignments/Syntax-Directed-Translation/) | Syntax-directed translation and the MiniLang translator in C |
| [Assignment 4 Part I](assignments/Assignment-4-Part-I/) | Translation schemes and intermediate code design |
| [Assignment 4 Part II](assignments/Assignment-4-Part-II/) | Intermediate code generation and interpreter validation |
| [Assignment 5](assignments/Assignment-5/) | Code generation, register allocation, and optimisation |

Open an assignment folder for its README, toolchain requirements, and commands to reproduce the checks.
