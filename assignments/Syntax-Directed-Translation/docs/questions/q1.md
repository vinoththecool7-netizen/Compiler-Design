# Q1 Synthesized Attributes

### Shared specification and Student A analysis

An SDD attaches equations to grammar productions; the resulting attribute grammar gives semantic values to individual occurrences in a parse tree. The numeric rules below use C double arithmetic, with an error if the right operand of division is zero. The implementation also accepts decimal literals and reserves identifiers for the postfix and AST exercises.

```text
E → E₁ + T    E.val = E₁.val + T.val
E → E₁ - T    E.val = E₁.val - T.val
E → T         E.val = T.val
T → T₁ * F    T.val = T₁.val * F.val
T → T₁ / F    T.val = T₁.val / F.val
T → F         T.val = F.val
F → ( E )     F.val = E.val
F → num       F.val = num.value
```

A numeric terminal gets its value from the lexer. Every other value uses only child attributes. Therefore the SDD is S-attributed; a parent value must follow its operands. Left-to-right postorder is one valid schedule, while independent subtrees may swap. The generated LALR parser shifts terminals and creates a node and computes its attributes on each reduction.

### Student B height rules and Student A experiment

Each terminal has height 0; for every E, T or F production, the left side has height 1 + max(child heights), including punctuation children. The left-recursive grammar leans left; rewriting as E → T + E or T − E and T → F * T or F / T leans right and changes associativity if values are computed naively.

Figure 1. Both grammars give the same heights on chains of addition.

For 1, 4, 16 and 64 operands the observed heights were 3, 6, 18 and 66. In a plain addition chain, n operands give n + 2 edges, 5n − 1 nodes and 9n − 1 attributes. The spine gains one level per extra operator. The shapes can have different heights on mixed terms: 2*3+4+5+6 gave heights 7 (left) and 6 (right). Naive right recursion would also evaluate 8−3−2 as 7 instead of 3.
