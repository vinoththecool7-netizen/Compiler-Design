# Q4 Postfix Translation Scheme

### Shared conversion and Student B action placement

An SDD says what to compute; an SDT places actions in the grammar to say when. For a binary expression, the SDD is parent.post := left.post ⋅ right.post ⋅ op. Unit productions copy the child, parentheses copy E and a leaf supplies its spelling. Streaming the three parts gives this scheme:

```text
E → E + T {emit("+")} | E - T {emit("-")} | T
T → T * F {emit("*")} | T / F {emit("/")} | F
F → ( E ) | id {emit(id.lexeme)} | num {emit(num.lexeme)}
```

```text
E( E(T(F(a {1:a}))), +,
   T( T(F(b {2:b})), *,
      F( (, E(E(T(F(c {3:c}))), -, T(F(d {4:d})), {5:-}), ) ),
      {6:*} ),
   {7:+} )
Output: a b c d - * +
```

The numbered action nodes are the last child of the production that emits them. An LR reduction runs the action when the whole RHS is on the stack. Moving the outer + action before T emits a + b c d - *, which is no longer postfix. A mid-production action needs to run before the RHS is complete, often using an empty marker.

### Student A experimental and engineering analysis

| Input | Observed postfix | Actions |
| --- | --- | --- |
| a+b*(c-d) | a b c d - * + | 7 |
| a+b*c | a b c * + | 5 |
| a-b-c | a b - c - | 5 |
| a/b/c | a b / c / | 5 |
| (a+b)*c | a b + c * | 5 |
| a*(b+c/d) | a b c d / + * | 7 |

For addition chains of 1, 4, 16 and 64 operands, the program emits 1, 7, 31 and 127 actions: one per operand and binary operator. Q1 computes numeric attributes at comparable child-before-parent points; postfix emits symbolic tokens and does not evaluate the operations.

```text
E → T R       R → + T {emit("+")} R | - T {emit("-")} R | ε
T → F U       U → * F {emit("*")} U | / F {emit("/")} U | ε
```

With recursion removed, emit after the new right operand and before recurring, preserving the left fold. Buffer partial output until acceptance, especially under recovery, and retain stack attributes until reduction. Prefer on-the-fly emission when local dependencies are available and the result can be committed transactionally; build a tree when later passes need global context.
