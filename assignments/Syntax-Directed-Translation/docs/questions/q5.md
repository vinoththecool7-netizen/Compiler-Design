# Q5 Parse Tree and AST Construction

### Shared specification and Student A pointer flow

```text
S → id = E        S.node := mkNode("=", mkLeaf(id,entry), E.node)
E → E₁ op T       E.node := mkNode(op, E₁.node, T.node)  op ∈ {+,-}
T → T₁ op F       T.node := mkNode(op, T₁.node, F.node)  op ∈ {*,/}
E → T; T → F     copy the child node reference
F → ( E )         F.node := E.node
F → id | num      F.node := mkLeaf(token, entry or value)
```

The C constructors allocate AST nodes and return pointers. Unit and grouping rules pass a reference upward without making a copy. Identifier spelling serves as the AST leaf handle in this standalone parser; MiniLang resolves actual symbol types.

```text
E → T R          R.inh := T.node; E.node := R.syn
R → op T R₁      R₁.inh := mkNode(op, R.inh, T.node); R.syn := R₁.syn
R → ε            R.syn := R.inh
T → F U          U.inh := F.node; T.node := U.syn
U → op F U₁      U₁.inh := mkNode(op, U.inh, F.node); U.syn := U₁.syn
U → ε            U.syn := U.inh
```

R is E′. Its inherited accumulator carries the tree already built to the left. For a = b + c * d, make leaves for a, b, c and d; reduce c and d to *(c,d), then +(b,*) and finally =(a,+). A right-recursive grammar without the inherited left fold would produce the wrong AST for b−c−d.

```text
Parse tree (all children shown, nested notation)
S(id(a), =, E(E(T(F(id(b)))), +, T(T(F(id(c))), *, F(id(d)))))
AST: =(a, +(b, *(c,d)))
```

### Student B size comparison and cross understanding

| Operands in RHS | Full parse nodes | AST nodes | Nodes removed |
| --- | --- | --- | --- |
| 1 | 7 | 3 | 4 |
| 4 | 22 | 9 | 13 |
| 8 | 42 | 17 | 25 |
| 16 | 82 | 33 | 49 |
| 64 | 322 | 129 | 193 |

Both grow linearly for these chains. The sample assignment has 16 concrete nodes and 7 AST nodes. Grouping punctuation, unit nonterminals and separate operator tokens are removed or represented by operator nodes. The saving rises from 4 nodes at one operand to 193 at 64. The ratio varies with parentheses and operator mix, and the counts do not measure heap bytes. This implementation keeps both structures, so the memory benefit applies when later passes retain only the AST.
